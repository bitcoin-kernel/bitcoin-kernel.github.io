Verify a Bitcoin block.

Pick a random block, or type a height. The block is fetched live and its proof of work, merkle root and structure are checked right here in your browser. No server. The validator is the page.

Phase 1: this checks proof of work, the merkle root, the witness commitment and block structure, all of which live inside the block itself. Script and signature validation needs the spending history (the prevouts), which is phase 2. So a pass here means the block is structurally sound, not that every signature was checked.

An independent JavaScript implementation. Block data from mempool.guide. bitcoin-kernel
